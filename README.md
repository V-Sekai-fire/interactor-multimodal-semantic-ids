# interactor-multimodal-semantic-ids

Design records for giving every item one semantic ID, quantized from its text, image, mesh, audio and body-phenotype embeddings.

## What it is for

`decisions/` holds the accepted and proposed records and the exploration notes that led to them; the code they describe is not in this tree. RFD 2268 frames the work as a decision model inside the loop rather than a service beside it.

## Build and run

There is nothing to build. `prek run --all-files` checks the Markdown formatting.
